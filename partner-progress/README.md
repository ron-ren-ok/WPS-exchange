# 合作方日报

工作流每天北京时间 04:10 运行，从 Google 表格「合作方新增血量」及「目标完成度」读取同一份数据，先发送血量合作方日报，成功后等待3秒，再发送新增合作方日报。

- 定时及手动触发默认使用生产 Webhook；验证时显式选择 `webhook_target=test`，使用 `WPS_WEBHOOK_URL_TEST`。
- 按目标类型分组：「合作方预算目标」的合作方进入血量日报，展示新增和血量；「合作方新增目标」的合作方进入新增日报，只展示新增。保留原有按月目标配置选取合作方的规则。
- 每个合作方的浅灰引用标题使用黑色加粗文字，分两行显示：第一行是合作方、最新数据日及实际目标完成度；第二行是本月累计和月底预测。未达标时显示「完成度」，达标后显示 ✅。显式换行避免手机上长标题截断金额。
- 每个指标固定四列：绝对值、当日环比、本期7日均环比、上期7日均环比。
- 最新数据日为9/27时，三项环比分别为：9/27 vs 9/20；9/21–9/27日均 vs 9/14–9/20日均；9/14–9/20日均 vs 9/7–9/13日均。日期范围包含起止日；新增、血量口径一致，不再展示28日均或12周字符趋势图。
- 各合作方以其目标指标最新有数据日为截止日。日均仅对窗口内有数据的日期求均值；数值0保留，缺失不补0。缺失值或比较基期为0时显示 `—`。
- 月底预测保留原算法：本月累计 + 近14个自然日内已回传日期的日均 × 本月剩余天数。
- 新增单位为万人，血量单位为万美元；标题累计及预测使用该日报目标指标的单位，卡片不再显示单位说明。
- 四列口径说明移到「查看明细」上方，采用灰色文字和浅灰左侧竖线，不填充背景；其上方是一条原生卡片分割线。发送脚本把独占一段的 Markdown `---` 转为 `hr` 组件。
- Markdown指标行之间使用两个真实换行，引用标题内部用两个空格加换行保持同一背景块。所有加粗内容的结束标记后加空格，兼容手机端解析；标题通过 `<font color='#000000'>**…** </font>` 设置黑色加粗。不开启图片推送。
- 数据读取范围为长表 `A:E` 的完整已用区间，不设固定行数上限。

```sh
python scripts/send_partner_progress.py --revenue-output revenue.md --new-output new.md
python -m unittest discover -s tests -v
```
