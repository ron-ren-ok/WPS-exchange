# 合作方日报

工作流每天北京时间 04:10 运行，从 Google 表格「合作方新增血量」及「目标完成度」读取同一份数据，先发送血量合作方日报，成功后等待3秒，再发送新增合作方日报。

- 定时及手动触发默认使用生产 Webhook；验证时显式选择 `webhook_target=test`，使用 `WPS_WEBHOOK_URL_TEST`。
- 按目标类型分组：「合作方预算目标」的合作方进入血量日报，展示新增和血量；「合作方新增目标」的合作方进入新增日报，只展示新增。保留原有按月目标配置选取合作方的规则。
- 合作方名单自动排除最近6周无数据的合作方：以本次播报全表最新数据日为统一截止日，检查含截止日在内的42个自然日；新增或血量任一指标有已回传数值即视为活跃，数值0也算数据。两项指标都没有数据则不进入播报名单，不删除表格历史数据或目标配置；后续重新回传数据会自动恢复。目标配置及目标指标当月数据仍是播报必要条件。
- 某组没有符合条件的合作方时只显示「暂无符合条件的合作方」；两组都为空也不因正常筛选而让工作流失败。源表空白、目标配置缺失等读取或配置错误仍然报错。
- 每个合作方的浅灰引用标题分两行显示：第一行是合作方、最新数据日及「累计→次日→月末」完成比例；第二行只显示「累计」和同一顺序的三个绝对值，省略重复的「次日、月末」标签及箭头空格。合作方及数值黑色加粗，日期和其后的竖线不加粗。实际未达标用 ⏳，达到或超过100%用 ✅；预测比例不使用达成图标。
- 指标行只显示绝对值和当日环比。最新数据日为9/27时，环比是9/27 vs 9/20；删除本期和上期7日均环比。
- 血量日报仅血量行附6周字符柱状图；新增日报在新增行附柱状图。六个位置从左到右由旧到新，各为7个自然日内已回传日期的日均。截止日9/27时，最右侧是9/21–9/27均值，前一根是9/14–9/20，以此类推，最左侧是8/17–8/23。日期范围包含起止日，不按自然周对齐。
- 柱高以0为基准，按该合作方六周最高均值归一化为8级字符，真实0用最低柱 `▁`，没有数据的窗口用 `·` 保留位置，不能把缺失补成0。六周柱高仅用于该合作方的趋势，不跨合作方比较绝对量。
- 各合作方以其目标指标最新有数据日为截止日。日均仅对窗口内有数据的日期求均值；数值0保留，缺失不补0。缺失值或比较基期为0时显示 `—`。
- 月底预测保留原算法：本月累计 + 近14个自然日内已回传日期的日均 × 本月剩余天数。
- 次日预测：本月累计 + 同一近14日均值；指合作方最新数据日的下一日，并非播报日期的下一日。三项比例均为对应金额除以本月目标，使用未舍入金额计算。若下一日跨月，「次日」显示 `—`，避免用本月目标计算下月完成比例。
- 新增单位为万人，血量单位为万美元；标题累计及预测使用该日报目标指标的单位，卡片不再显示单位说明。
- 「查看明细」上方只保留灰字说明「顺序：累计→次日→月末」，不显示柱图注释；采用浅灰左侧竖线、不填充背景，其上方是一条原生卡片分割线。发送脚本把独占一段的 Markdown `---` 转为 `hr` 组件。
- Markdown指标行之间使用两个真实换行，引用标题内部用两个空格加换行保持同一背景块。所有加粗内容的结束标记后加空格，兼容手机端解析；标题通过 `<font color='#000000'>**…** </font>` 设置黑色加粗。不开启图片推送。
- 数据读取范围为长表 `A:E` 的完整已用区间，不设固定行数上限。
