# Yandex Partner Sync

Yandex 换量弹窗与气泡数据同步项目，不依赖 AI 或本机浏览器。

## 工作内容

- 调用 Yandex Distribution API，读取 `Installations` 与 `Partner reward`。
- 以版本化 Profile 校验国家、Pack ID、指标字段与 API 模板指纹。
- 写入 Google Sheet「合作方新增血量」长表：
  - Profile `换量弹窗` 写入合作方 `Yandex`、运营位 `换量弹窗`；
  - Profile `气泡` 写入合作方 `Yandex`、运营位 `气泡`。
- 长表字段是「日期、合作方、运营位、新增、血量」，以这三项共同定位一条记录；已有记录更新指标，不存在则追加。
- 默认回补并覆盖截至北京时间昨天的最近 7 个自然日（含首尾），不扩大到更早的历史缺口。手动填写 `start_date` 时使用指定起点；填写 `end_date` 时使用指定终点。只填终点时起点为终点减 6 天，只填起点时终点为北京时间昨天。
- API 明确返回的零值可以覆盖旧值；有数据日期之间省略的日期标记为推断零值。API 未返回的日期若在表里已有任何非零或异常指标，整次任务在写入前失败，保留旧值。连续前置或末尾缺报日期跳过并输出日志，不将末尾缺报当作零活跃。
- 全量读取 `A:E`，不受 10000 行限制；按「日期 + 合作方 + 运营位」检查重复记录。写入后回读本次源记录并核对两项指标及重复键，核验不通过时任务失败。

## GitHub Actions

工作流可手动执行，并在每天北京时间 03:00 定时运行。

必须配置以下 GitHub Actions Secrets：

- `YANDEX_DISTRIBUTION_TOKEN`（可保存纯 Token，或带 `OAuth ` 前缀）
- `GOOGLE_SHEET_SERVICE_ACCOUNT_JSON`

服务账号必须已被授予目标 Google Sheet 的编辑权限。凭证绝不提交到仓库。手动补数时可在 Actions 页面填写 `start_date`、`end_date`，日期范围包含首尾。默认开启 `allow_overwrite`；取消后允许补空值和追加，但任何已有非空差异都会在写入前阻止整次任务。定时运行默认覆盖，命令行可用 `--no-allow-overwrite` 禁止覆盖。缺报保护始终生效，覆盖开关不能绕过。

工作流限制 Yandex 同步任务串行执行，并在同步前运行单元测试。Yandex 请求、Sheets 读取与幂等更新对 429、5xx、网络错误和超时最多尝试 4 次，退避等待并尊重不超过 30 秒的数字 `Retry-After`。鉴权及其他非暂时性错误不重试。

追加发生暂时性错误后先回读：全部记录存在且数值一致则确认成功；429 拒绝请求时仅重试尚不存在的记录。超时或 5xx 后若回读仍不完整，停止并要求检查后重跑，不盲目重发可能仍在服务器执行的追加请求。
