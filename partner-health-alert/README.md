# 三方换量合作方健康告警

`.github/workflows/partner-health-alert.yml` 每天北京时间 09:00 运行。定时任务使用生产 webhook；手动运行默认使用测试 webhook。

数据直接读取 Google Sheet `26年-三方运营` 的 `数据解压!P:Y`：

- 新增：北京时间昨天与 7 天前同一天比较，绝对变化至少 50 且相对变化至少 20%。
- 次日留存：北京时间前天的成熟 D1 与 7 天前同一天比较，变化至少 3 个百分点且相对变化至少 15%。
- 卸载率：北京时间昨天与 7 天前同一天比较，变化至少 3 个百分点且相对变化至少 30%。

上涨、下跌都可能触发。两个阈值必须同时满足；`0` 是有效值，空值不按 `0` 处理。

同一合作方、同一指标、同一方向连续异常时，只在第一次进入异常时推送；恢复正常后再次异常，或方向发生变化时重新推送。超过半数可比较合作方在同一指标上同时向同一方向异常变化时，推送“数据异常”，不再逐个发送该指标的合作方告警。

应有观察日缺失、活跃合作方数据缺失或相关比较窗口出现公式错误时，也归为“数据异常”。没有新告警或数据异常时不调用 webhook。

## GitHub Secrets

- `GOOGLE_SHEET_SERVICE_ACCOUNT_JSON`：可读取目标 Google Sheet 的服务账号 JSON。服务账号邮箱须以“查看者”身份共享到该表格。
- `WPS_WEBHOOK_URL`：正式 WPS 群机器人地址，仅供定时任务或明确选择 production 的手动任务使用。
- `WPS_WEBHOOK_URL_TEST`：手动运行的默认测试机器人地址。
- `WPS_WEBHOOK_KEY`、`WPS_WEBHOOK_SECRET`：仅在机器人启用签名校验时成对配置。

所有凭据仅从 GitHub Secrets 在运行时读取；脚本和日志均不会输出 Secret 内容。
