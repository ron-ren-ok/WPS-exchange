# 用户增长 KPI 播报

每日从 Google Sheet「三方&导量运营数据」只读获取 `新增&月活提取` 和 `目标`：

- 渠道：按 `新增&月活提取` 的在线渠道维度动态读取；当前为整体、三方合作、安卓导PC、SEM、官网、Affiliate、其他、微软商店、SEO。后续新增渠道无需改代码。
- 每个渠道三行：`渠道 MAD ⏳完成率（目标→实际）`、`新增：完成率（目标→本月累计）`、`昨增：昨日新增 柱图`。MAD 行使用 Markdown 引用块，新增和昨增保持普通段落。渠道名及 MAD、两项完成率加粗；MAD 实际达到或超过目标时显示 ✅️，未达成或目标待同步时显示 ⏳，所有数值保留一位小数，数量单位统一为万。
- 趋势：最近 8 个滚动七天窗口的新增日均柱图，从左到右由旧到新，以数据截至日为最后一个窗口末日。
- 目标：按 `目标` 页中的 `MAU` / `新增` 区块及 `2026-目标` 列动态解析。目标存在、但源数据尚未回传的渠道（例如当前的 Mac）会单独显示“暂未回传”，不会阻断其他渠道播报；旧版三方/导量/AFF 目标名称继续兼容。
- 推送顺序：整体、三方合作及 Affiliate、其他渠道（安卓导PC、SEM、官网、微软商店、SEO、Mac、其他）。每张卡均按顺序尝试发送并间隔 3 秒；即使有单张失败也会继续后续卡片，最后汇总失败项。

## GitHub Secrets

- `GOOGLE_SHEET_SERVICE_ACCOUNT_JSON`：可读取该表格的服务账号 JSON；须将服务账号邮箱以查看者权限共享给表格。
- `WPS_WEBHOOK_ACQUISITION`：正式群机器人地址。
- `WPS_WEBHOOK_URL_TEST`：测试机器人地址。

每日定时任务默认推送正式地址；手动触发默认推送测试地址。Webhooks 只在运行时读取，绝不输出到日志或仓库。
